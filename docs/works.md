# 作品库与本地作品包

2026-10-22：`/works` 和 `/works/:id` 提供作品库与详情。侧栏“作品库”统一包含全部作品、曲目列表、专辑、ASMR 与 CD 抓轨。共享信息架构、音乐多碟与ASMR详情目标见[页面设计](../../docs/ui-works.md)，服务端能力以[作品资料接口](../../server/docs/library/works.md)和[本地副本](../../server/docs/library/work-packages.md)为准。

## 当前功能

- 类型分类、主要参与者卡片、关键词与标签过滤、继续加载。
- 手工创建资料，独立详情阅读与编辑弹窗，按声明选择署名角色和编号来源。
- 关键词／标签保存在路由查询中，筛选变化清空旧分页；详情标签可回到筛选列表。
- 保存时携带幂等键和修订；明确失败的 4xx 响应允许修改后换键，原样重试保留键，409 冲突需明确刷新。
- 网络中断、超时、响应格式异常和 5xx 响应都视为结果未知：锁定原内容、修订与幂等键，只能重试确认同一次保存，或关闭并刷新查看。确认前不会换键重新新建或更新。服务端幂等记录保留 24 小时；本阶段不持久化浏览器待确认任务，离开或超过窗口后应先查看已保存资料再操作。
- 提交后离开页面不取消服务端写入；旧请求完成不会再导航或更新已经关闭的编辑器。
- 已保存但内容插件不可用的作品可以阅读，编辑按钮不可用。

类型、角色、编号名称来自 `/content-types`；页面不维护ASMR或音乐角色映射。侧栏对内置 `music/asmr` 使用短名称“专辑／ASMR”，其余类型显示声明名称。`api/works.ts`校验基本响应形状，页面沿用统一会话、CSRF、错误提示和取消机制。没有新增浏览器插件脚本加载。

`music` 类型显示为「音乐专辑」，覆盖专辑、EP 与单曲发行。选择分类及创建／编辑作品时显示内容插件提供的用途说明，明确可导入 CD 抓轨或数字发行的本地音频及附带资料。

作品库分组首次默认收起；点击父行任意位置统一切换展开／收起，支持 Enter／空格操作，切换时保留当前页面。“全部作品”子项进入作品总览。展开状态沿用现有用户偏好，按服务实例和账号保存在 localStorage，刷新／重开恢复上次状态。子项按完整路由及分类参数准确高亮，窄屏同时保留图标和短文字。原顶部分类按钮移至侧栏，分类页只保留标题、筛选和作品列表；折叠与跨页导航不更换播放会话。

“专辑”使用 `/works?contentType=music`，“ASMR”使用 `contentType=asmr`；“CD 抓轨”使用 `packageKind=cd_dump`，按已标记的本地副本筛选。关键词、标签及分页保留这些条件；多个抓轨副本不会重复列出同一作品。CD 抓轨并非新的内容类型，音声 CD 抓轨也能在此出现。

“曲目列表”只浏览普通音乐，Server 在分页及分类聚合前排除 ASMR 作品和 CD 抓轨副本的音频。专辑、歌手、流派和文件夹不会残留仅属于这些内容的分类；共用分类只统计普通音乐。前端沿用服务端范围，不在当前页二次过滤。离开分类页面释放查询，确认导入后返回曲目列表会重新查询；作品详情继续提供完整音轨和附件。

确认导入成功后清空各来源的曲目缓存并取消旧读取，即使确认请求晚于页面离开才返回，也不会恢复旧行；正在显示的曲目列表重新加载。播放器和既有队列继续保留。歌单通过 `GET /source-tracks/{id}` 解析明确保存的音轨引用，每页去重且最多四个并发请求，ASMR／CD 抓轨音频不会因普通曲库过滤而无法读取；临时错误可重试，其他用户或已不存在的引用显示为不可读取。

## 本地作品包

详情页支持从本人可用的本地来源中选择根目录和多层子目录。导入分为读取预览和确认入库两步：预览显示完整目录树、目录／音轨／附件数量和警告，不发布资料；确认后刷新作品包。重复导入同一来源、根目录和相对路径会更新原作品包。

界面将通用持有集合称为“本地副本”。导入需明确选择“普通目录／CD 抓轨”，预览固定副本类型；更改类型后重新生成预览。详情显示类型标记，重新导入沿用原位置并允许更改类型。CD 视图中新建作品后默认打开一次 CD 抓轨导入；刷新不会重复自动打开。退出导入保留已创建作品资料，只有确认抓轨副本后才会出现在 CD 列表。

作品包保留多层目录，多个包可切换，各目录可折叠。目录的播放与入队按钮只收集该目录及子目录内可用音轨，按服务端顺序播放；用户应选择具体版本目录，避免将不同编码或版本混在一起。单曲播放与目录播放沿用现有播放器；失效音轨保留文件位置并明确标记不可播放。

附件使用作品、包和节点标识访问服务端，不接受外部网址或任意文件路径。页面用独立弹窗显示不超过 16 MiB 的 PNG／JPEG／GIF 图片、以及不超过 1 MiB 的 UTF-8 纯文本；文本内容不作为 HTML 运行。其他类型（含 WebP）和超过预览大小的附件仅提供下载。关闭图片预览会释放临时对象地址。目录与附件弹窗显示常见格式短名，未知格式显示“音频”或“附件”。

确认导入携带调用方保留的幂等键。网络中断、超时、5xx 或无法识别的响应会锁定原预览与键，允许同键重试或关闭并刷新作品包；409 要求重新预览。请求未完成时禁止重复确认，离开路由后旧请求完成不再更新已卸载的页面。服务端幂等记录保留 24 小时；浏览器不持久化待确认导入，重新打开页面后应先查看已导入的包再操作。预览和确认使用较长但有上限的请求超时，目录浏览仍沿用默认超时。

此阶段未提供音乐碟片语义、CUE 分轨、自动刮削、续听记录或作品封面设置；卡片不使用虚构图片。附件图片与曲目播放器的封面资料独立。

## 验证

API单元测试为 `tests/unit/api/works.test.ts`；模拟接口的浏览器测试为 `tests/e2e/works.spec.ts`，覆盖声明驱动、创建／编辑、幂等重试、已提交但响应丢失后的内容锁定、离开页面后的延迟完成、真实错误码的修订冲突、未知类型只读、筛选分页及窄屏布局。真实Server闭环验证为 `tests/e2e/works-real.spec.ts`，覆盖实际登录、声明、写入、并行编辑冲突和服务重启后的资料保留。

本地包的 API／目录范围单元测试为 `tests/unit/api/work-packages.test.ts`。`tests/e2e/work-packages.spec.ts` 覆盖多层选择、完整预览、导入、目录播放范围、折叠、失效音轨、安全附件、未知结果重试、409 重新预览、关闭刷新和离页后的延迟完成。`tests/e2e/work-packages-real.spec.ts` 使用真实本地来源、多层 WAV、PNG 和 UTF-8 文件，检查导入、播放请求与实际音频、附件字节、重复导入与服务重启后的保留。

模拟接口测试不代替真实Server验证；构建、运行与具体测试结果以本次执行记录为准。

`tests/e2e/work-navigation.spec.ts` 验证首次收起／刷新保留展开或收起、键盘操作、路由精确高亮、动态类型、CD筛选条件、跨页播放保持及窄屏布局。作品包真实测试另覆盖普通副本改为CD抓轨、分类查询和重启持久化。

`tests/e2e/work-library-boundaries.spec.ts` 验证导入后缓存清空（含刷新失败）、当前音频不中断、歌单显式引用播放，以及混合来源专辑的可见数量与完整播放。对应单元测试为 `tests/unit/library/invalidation.test.ts` 和 `playlist-tracks.test.ts`。
