# 作品库第一阶段

2026-10-22：新增 `/works` 和 `/works/:id`，作品库入口位于曲目列表之前。共享信息架构、音乐多碟与ASMR详情目标见[页面设计](../../docs/ui-works.md)，服务端能力以[作品资料接口](../../server/docs/library/works.md)为准。

## 当前功能

- 类型分类、主要参与者卡片、关键词与标签过滤、继续加载。
- 手工创建资料，独立详情阅读与编辑弹窗，按声明选择署名角色和编号来源。
- 关键词／标签保存在路由查询中，筛选变化清空旧分页；详情标签可回到筛选列表。
- 保存时携带幂等键和修订；明确失败的 4xx 响应允许修改后换键，原样重试保留键，409 冲突需明确刷新。
- 网络中断、超时、响应格式异常和 5xx 响应都视为结果未知：锁定原内容、修订与幂等键，只能重试确认同一次保存，或关闭并刷新查看。确认前不会换键重新新建或更新。服务端幂等记录保留 24 小时；本阶段不持久化浏览器待确认任务，离开或超过窗口后应先查看已保存资料再操作。
- 提交后离开页面不取消服务端写入；旧请求完成不会再导航或更新已经关闭的编辑器。
- 已保存但内容插件不可用的作品可以阅读，编辑按钮不可用。

类型、角色、编号名称来自 `/content-types`；页面不维护ASMR或音乐角色映射。`api/works.ts`校验基本响应形状，页面沿用统一会话、CSRF、错误提示和取消机制。没有新增浏览器插件脚本加载。

当前作品记录未关联音轨、目录或附件；页面明确说明手工资料范围，不显示无实际能力的播放、导入、刮削、续听或封面操作。卡片不使用虚构图片。现有曲目列表和播放器继续提供原有音频功能。

## 验证

API单元测试为 `tests/unit/api/works.test.ts`；模拟接口的浏览器测试为 `tests/e2e/works.spec.ts`，覆盖声明驱动、创建／编辑、幂等重试、已提交但响应丢失后的内容锁定、离开页面后的延迟完成、真实错误码的修订冲突、未知类型只读、筛选分页及窄屏布局。真实Server闭环验证为 `tests/e2e/works-real.spec.ts`，覆盖实际登录、声明、写入、并行编辑冲突和服务重启后的资料保留。

模拟接口测试不代替真实Server验证；构建、运行与具体测试结果以本次执行记录为准。音乐碟片／音轨列表、ASMR包树、封面附件和续听组件均按后续阶段增加。
