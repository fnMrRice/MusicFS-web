## 扫描状态兼容

- `retry_wait` 继续有截止时间的轮询，并显示等待自动重试。重试进入 `running` 时即使保留上次错误，也不会被误判为终态。
- `paused` 立即结束等待，提示处理来源或权限问题后重新提交。原幂等键仍代表原任务，重新提交应使用新键。
- 页面按 `paused`、`retry_wait` 优先显示状态；来源同时离线时不会遮蔽暂停说明。
- 最简页面保留现有来源刷新与曲目列表，没有新增扫描提交或任务管理页面。扫描等待器用于真实 Server 测试准备。

此前通过的 4 项针对性单元测试覆盖重试携带旧错误、暂停立即返回、固定总等待期限和页面提示。本次真实 Edge 测试实际将合成音乐目录移出授权位置，观察扫描返回 `paused` 与 `SOURCE_OFFLINE`，随后验证页面显示“扫描已暂停”“重新提交扫描”，已发布曲目仍保留；目录恢复后播放和新扫描成功。

本轮浏览器测试未人为制造短暂上游错误来触发真实 `retry_wait`；该状态的 Web 轮询分支由上述单元测试覆盖，不能将其描述为浏览器已实测自动重试。
