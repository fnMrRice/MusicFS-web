# Web 鉴权约定

- 同源 `/api/v1`；开发代理保留真实 Origin，Server 精确允许 `http://127.0.0.1:5173`。
- 首次登录只在请求头发送显式输入的 Bearer token；成功后清空输入。不写 URL、浏览器存储或构建变量。
- 后续使用 HttpOnly、SameSite=Strict cookie。生产 HTTPS 要求 Secure；本机 HTTP 例外由 Server 配置限定。
- 修改请求发送内存中的 `X-CSRF-Token`；退出同样校验 Origin 与 CSRF。
- `<audio>` 直接访问 Server 返回的同源地址，由 cookie 鉴权；不把整首音频下载成 Blob。
- 登录失效清理页面身份和媒体。错误只呈现中文业务说明与请求编号，不回显凭据或内部路径。
- React 播放器、队列、歌单和曲库缓存随退出／401 清空；队列的本地缓存同时删除，更换 API 地址时也清空。页面请求在卸载后取消，迟到结果不发布。
- 临时队列以 `localStorage` 固定键 `musicfs:playback-queue:v1` 仅保存一份，不按账号或服务地址分别留存；只保存白名单曲目元数据、顺序、重复项、选中索引、模式、随机播放历史和下一首优先项。刷新恢复队列，不自动播放，不持久化或恢复旧播放会话、流地址、token 或 CSRF。
- 音量和静音前音量保存在同一站点共用的固定键 `musicfs:volume`；其他本机偏好和最近搜索以编码后的实例／用户 ID 隔离，异常或禁用的存储回退为内存。除队列白名单元数据与导航状态外，只保存主题、音量、分组、处理偏好和关键词，不保存 token、CSRF、流地址或服务器路径。
