# MusicFS-web 设计入口

2026-10-22 作品库增量：新增按内容类型浏览的作品卡片和独立资料详情／编辑，插件声明决定角色与编号选项；实现边界见[作品库第一阶段](works.md)，音乐多碟与ASMR目录树的后续布局见[共享页面设计](../../docs/ui-works.md)。

当前阶段（2026-10-10）：已由 React 接管界面，提供共享外壳、曲目表、搜索／推荐、歌单、专辑和设置；已有接口接入、未支持能力及验证范围见 [React 交付记录](react-validation.md)。历史最小页面记录保留于 [实施记录](progress.md)。

服务状态入口在设置左侧，以状态点展示最近一次健康检查结果，替换原先固定的“已连接”文字。点击可查看状态、检查时间并手动重新检查；登录后立即检查，前台页面每 30 秒检查一次，恢复网络或回到页面时重新检查，请求超时为 5 秒。沿用 `/health/ready`：区分运行正常、服务未就绪（含 503）、无法连接、协议不兼容、实例变更和其他异常；不以登录快照或单个插件状态代替服务就绪。实例变更仅提示刷新重新连接，不修改当前会话身份。检查不代表所有音乐来源与插件可用，详细状态仍在设置中查看。

按 [TypeScript + React 开发方案](react-development.md)和[共享 UI 设计](../../docs/ui-design.md)实现 Web。顶部右侧依次为服务状态、设置、换肤和账号头像，不含桌面窗口控制。账号入口仅显示默认头像，悬停、聚焦或点击后展开个人信息卡片，显示放大的头像、昵称、当前用户标识和角色，底部提供退出登录按钮；侧栏不再放置账号。昵称通过 `/me/profile` 读取，未填写时以用户标识作为主标题；卡片内“修改昵称”打开编辑弹窗，保存至服务端后更新显示，空白输入清空昵称。昵称最多 80 个 Unicode 码点，不接受控制字符；账号退出或切换时清理资料与在途请求。头像上传仍未支持，昵称不改变鉴权身份或偏好隔离键。接口接入范围见[依赖清单](react-api-readiness.md)，Server 侧需求见[缺口交接](../../server/docs/contracts/web-integration.md)。

旧版原生 DOM 页面与原生音频控件已移除；React 自定义播放栏沿用原流、处理输出和 NCM 控制核心。「设置 → 音乐源」在「本地音乐」标题右侧提供「添加本地目录」，标题下只列出已添加的目录，每行右侧依次提供减号删除、编辑、刷新。添加弹窗以 Server 允许目录为多个树根，逐层展开并选择根或子目录；允许范围不可编辑，已有目录不能在添加弹窗中取消。编辑修改目标目录的名称与查找设置，其他目录保持；删除只移除配置，保留访问授权、磁盘文件及已有曲库记录。

目录行的「刷新」只刷新该目录；来源标题行同样显示「刷新」，辅助说明为「刷新全部目录」。刷新全部目录时先读取一次最新目录与配置，再按目录分别以 `options.refreshMetadata:true` 提交任务，每个目录使用独立幂等键，不修改保存的配置。一个目录正在运行时仍可添加其他目录任务，服务端合并同目录的活动任务。封面与歌词可替换已有自动内容，保留手动选定的来源内容和 Recording 封面；内容相同或无新候选时保留现状。

右上角服务状态右侧提供「任务队列」，徽标显示当前查看范围的所有活动任务数。默认只看自己的任务，管理员可切换查看所有任务及所有者；任务卡片显示目录、来源、文件读取或元数据更新阶段、处理数及更新／保留／未找到／失败汇总。排队任务可取消，运行任务可中断，已完成的结果保留。界面以服务端聚合后的任务终态为准，页面切换或重载后从任务列表恢复，不把扫描完成误作元数据更新完成。未知提交只保存尚未确认目录的原请求和幂等键；继续确认不会重发已成功的目录。服务端明确拒绝的失败项可读取最新配置重新提交或移除。任务完成后刷新曲库视图。

播放栏曲目信息下方显示「源封装 → 内层编码 → 服务端发送编码 · 发送采样率 · 发送码率 · 声道数」，例如「NCM → FLAC → MP3 · 48 kHz · 112 kbps · 2 声道」。源封装和内层编码读取来源曲目 `container`、`codec`，发送编码、采样率、码率与声道读取当前播放描述 `outputProfile`；原流省略相邻重复阶段，同编码转码仍保留输入和输出。PCM 子类型统一显示 PCM，E-AC-3 显示 DDP。采样率读取 `outputProfile.sampleRate`，换算为 kHz 展示（例如 44.1 kHz、48 kHz），缺失时标明「采样率未知」；码率按十进制 kbps 展示，悬停分别显示来源码率与发送码率；发送码率缺失时标明「码率未知」，不借用源文件码率。声道缺失时只按明确的声道布局补全，仍未知则标明「声道未知」，不默认双声道。这里不表示浏览器解码结果或音响物理输出；不再显示播放中、暂停、播放结束等阶段文字，播放错误仍通过原有提示展示，本地音效标记保留。

播放栏移除停止按钮，保留播放／暂停。模式按钮依次切换「顺序播放 → 列表循环 → 单曲循环 → 随机播放」，默认顺序播放；模式和队列只保留在当前浏览器会话。列表循环在队列末尾回到开头，单曲循环仅在自然结束时重播当前曲目，手动上下首仍按队列移动。随机播放在多首时避开当前队列项，上一首返回随机播放历史。队列面板的「打乱队列」只重排当前队列，保留正在播放的曲目、进度和对应选中项，不修改歌单；不足两首时禁用。窄屏仍提供模式切换和队列入口。

播放栏两个时间可分别点击切换：左侧为当前时间／剩余时间，右侧为总时间／剩余时间，默认显示当前时间与总时间。剩余时间以负号标识，按曲目总时长减去当前进度计算，最低为零；时长未知时显示「—」。拖动进度条时按预览位置更新显示，点击时间只改变显示方式，不改变播放或定位；两侧选择独立，换曲后保留，页面刷新后恢复默认。

音量滑杆在悬停、聚焦和调整时显示百分比，播放栏与设置中的音量同步更新。音量为零时，静音按钮显示带斜杠的扬声器；取消静音恢复此前的非零音量。当前音量和最后一次非零音量通过 `localStorage` 的固定键 `musicfs:volume` 保存，当前浏览器同一站点共用，刷新或服务重启后恢复；无有效保存值时默认使用 80%，已保存的 0% 保持静音。

播放栏的「歌词」入口打开歌词窗，有歌词时只展示歌词；没有歌词或歌词文本为空白时展示当前封面（若有），下方仅提示「暂无歌词」，不再显示来源及逐句定位说明。标题旁提供「固定歌词／取消固定歌词」。未固定时点击外部关闭；固定后外部操作不关闭歌词窗，底部歌词按钮作为显示／隐藏开关，显示时高亮选中。隐藏、关闭或按 Escape 只收起窗口，不取消固定；取消固定后恢复临时弹窗行为。固定偏好通过 `localStorage` 按实例和账号保存，默认不固定；刷新后有曲目时恢复固定歌词窗。队列临时覆盖已显示的固定歌词窗，关闭队列后返回；此前主动隐藏的歌词窗保持隐藏。

播放队列提供相同的固定行为：「打乱队列」紧邻标题右侧，「固定播放队列／取消固定播放队列」位于关闭按钮左侧。固定偏好独立按实例和账号保存，默认不固定；刷新后恢复已固定的队列面板，队列内容仍只保留在当前会话。底部队列按钮切换显示和隐藏，显示固定队列时高亮选中；关闭、Escape 和隐藏均保留固定偏好。队列与歌词共用一个面板位置，临时查看另一面板后返回之前显示的固定面板，主动隐藏的面板保持隐藏。按钮提示显示在独立浮层，避免被面板滚动边界裁切。

Web 用 `canPlayType` 将当前浏览器的格式支持情况随播放请求发送给 Server，包括 `audio/flac`。浏览器支持 FLAC 且无需强制转码、音效处理或声道转换时，Server 直接交付 FLAC；NCM 只解除外层加密，显示「NCM → FLAC」。确需转码时，Server 在目标编码支持的范围内选取最接近源码率的配置，来源码率未知则使用默认值；当前会话的定位和恢复沿用已协商配置。

逐目录设置包含递归查找，以及默认折叠的高级选项：限制递归深度、包含隐藏文件和目录、遵循 .nomedia 标记。启用递归默认深度 0，勾选深度限制后数字才可编辑，未限制或为 0 时查找全部子目录。默认不包含点开头及 Windows 隐藏项，并跳过含 .nomedia 的目录及子树。Server 通过 `rootImportDefaultsSupported` 声明逐目录设置能力，`roots[].importDefaults` 提供目录有效选项；旧 Server 未声明时只提供其支持的目录操作，不把共享选项伪装为独立设置。取消不保存；添加或编辑配置应用成功后自动扫描，删除目录不触发扫描。配置引发的自动扫描沿用逐目录设置，不属于显式刷新任务队列；页面保留自动扫描的排队、已发现曲目数及重试等待状态。首次没有已添加目录，本地来源始终使用插件自述名称；目录浏览由 Server 限定在授权范围内，Web 不读取浏览器所在设备的磁盘。下文长期职责不代表全部能力已经交付。

Server 与客户端共同约定由 [MusicFS 跨端架构](../../docs/architecture.md) 管理；[Server 内部设计](../../server/docs/architecture.md)与[音频处理](../../server/docs/playback/audio-processing.md)由 Server 仓库维护。本文件负责 Web 内部职责，OpenAPI、事件协议与协议 SDK 由 Server 发布。

Web 负责浏览器 UI、播放适配器、搜索、聚合歌单、来源选择与设置，并展示 Music Provider 提供的歌单推荐。与桌面端复用组件或资源的方式待验证后确定；不复制桌面宿主逻辑。需验证浏览器 codec、代理 Range、会话授权与部分来源不可用的展示。

本地与在线来源名称由 `/provider-instances`、`/online-instances` 的 `plugin: { id, name, localizedNames, features }` 提供，契约见 [插件身份与名称](../../server/docs/plugins/plugin-identity.md)。所有插件声明默认别名 `name`，Web 不维护插件 ID 到别名的映射。别名按规范化的当前语言标签精确匹配，再匹配同语言书写体系、基础语言、同语言且书写体系相同的地区标签，最终使用插件默认 `name`；不会把插件名称交给产品文案字典翻译。插件元数据在当前服务端登录会话内共享，退出、登录失效或接受新会话时清空；旧响应不能重新写入。旧 Server 或首次描述失败未返回 `plugin` 时显示“未知来源”，不展示实例配置名或实例编号；插件离线但仍有有效元数据时保留插件别名。

插件实例 ID 使用 UUID，仅用于请求、路由与状态关联。已绑定的平台账号显示“插件别名 · 账号用户名”，其中用户名来自服务端 `/online-instances` 的账号名称和账号视图 `displayName`，不使用配置中的实例名称；未登录时只显示插件别名。插件管理读取 `/admin/plugins` 每项的 `plugin` 和 `supportsMultipleInstances`，仅在插件声明支持多实例时追加对应账号用户名。本地来源仅允许一个实例，其目录配置仍可包含多个音乐目录；前端测试中的真实启动配置与模拟响应均使用固定 UUID。

插件管理的“插件列表”按插件分组，折叠摘要显示插件名、用途、插件 ID 和版本，不展示实例数量。用途使用插件声明的 `plugin.features`，例如音乐源、音频编解码、DSP 和元数据；`transform/thumbnail`、`tags/*` 与 `scraper/*` 统一声明 `metadata`，显示为“元数据”。摘要与类型筛选使用同一分类，仅依据用途声明，不改变插件角色或业务能力。已知功能使用产品译文，未知功能保留原始标识，无功能声明时显示“未分类”，不按插件 ID 猜测用途。管理接口可选的 `displayCount: { value, unit, localizedUnits }` 提供数字、默认单位及单位译文；Web 只选择当前语言的单位并展示，不按插件 ID、功能、实例数量或用户归属推算。本地音乐显示“n 个允许访问的目录”，由 Server 统计有效部署授权根，待配置或禁用时仍能显示；添加、编辑或删除音乐目录不会改变该授权数量。需要登录的在线音乐插件继续报告已登录平台用户数量（“x 个用户”）；自定义插件可提供自己的单位，单位与插件名称使用相同的语言匹配规则，不经过产品文案字典。零值正常展示，缺失或无效统计则隐藏，不回退为实例数量。Server 仅汇总当前管理范围内的统计；除宿主掌握的本地授权数量外，未运行或旧插件未提供完整统计时不展示数量。

插件之间用横线分隔，默认折叠，展开后逐项显示实例名称、所属 MusicFS 用户和运行状态；没有实例的插件仍显示摘要。版本来自管理接口必填的 `version`，随包插件尚未启动时使用与 Worker 同源的发行版本声明；“未知版本”仅作为旧 Server 缺失字段时的兼容提示，不代替服务端版本必填校验。“刷新插件列表”按钮紧邻标题右侧，刷新保留已展开的插件；待配置及停用待重启提示保留在对应实例内。

数据库与 DSP 也由 `/admin/plugins` 提供，分别声明 `database`、`audio-dsp` 用途，参与同一搜索与类型筛选。数据库摘要根据 `required` 显示“必需”，详情读取 `storage` 的后端、运行方式与健康状态，明确数据库不能停用、后端由服务端启动配置选择且修改后需重启。DSP 摘要根据 `dsp.chainState` 区分未配置、已配置未入链、已加入处理链；详情按节点 `position` 展示此插件在完整处理链中的原始位置、名称、版本、参数和内置／独立进程模式，保留跳号及重复名称节点。该视图反映服务端启动时的处理链配置片段，不代表当前播放状态，修改后需重启。基础设施条目使用这些详情替代空实例提示，不提供启停操作；新字段均可选，旧 Server 的普通插件响应继续按原有实例视图显示。

类型过滤器从完整插件列表的用途声明生成，默认不选任何类型，显示全部；可多选，插件包含任一所选用途就匹配。按住 Shift 点击类型时仅选择该类型，即使该类型已选中也保留；“插件类型”右侧问号提供操作说明。“全部”按钮清空类型选择，取消最后一个类型也恢复全部。搜索框紧随标题行的刷新按钮，窄屏时自动换行；按插件 ID、默认名称和各语言名称进行不区分大小写的包含匹配，忽略输入首尾空白；名称搜索与类型过滤同时满足才展示。无匹配时显示单独提示，与未安装任何插件区分。刷新保留搜索和类型选择，类型选项不会随搜索结果缩减；离开插件管理页后不持久化筛选。

需要登录的在线插件通过不同 UUID 实例分别承载 MusicFS 用户及各自的平台账号；不按昵称合并实例。管理员默认查看自己所属的在线实例及共享插件实例，勾选“显示所有用户实例”后请求 `/admin/plugins?allUsers=true`。其他用户的账号名称只使用该管理响应的 `accountName`，不会扩大普通 `/online-instances` 的账号访问范围；实例归属使用 `ownerUserId`。这项管理展示与服务端归属配置不提供新的 MusicFS 用户注册入口，当前登录入口仍只有管理员，具体配置和兼容范围见 [Server 插件管理](../../server/docs/plugins/plugin-management.md)。

设置页采用“音乐源 / 插件管理 / 播放配置 / 其他配置”四个标签页，默认打开音乐源。音乐源包含本地目录和平台账号；插件管理展示现有插件状态及刷新入口，仅管理员可读取管理数据，普通用户看到权限提示；播放配置包含服务端处理偏好和音量；其他配置包含语言、外观、连接与账号及退出登录。标签支持左右方向键、Home / End 移动焦点，Enter / 空格确认切换；窄屏横向滚动。所选标签写入地址参数，刷新后保留，旧目录管理链接仍直接打开音乐源。面板按需挂载，离开音乐源时终止尚未完成的平台授权；已保存偏好不受切换影响。

音乐源标签将本地与在线实例合并为单一“音乐来源”，按 `music-source` 功能声明筛选并按实例编号去重；账号登录、校验和退出操作放在对应来源内。元数据缺失的旧接口来源仍显示未知来源。

重复歌曲展开后的每个来源版本提供“详情”按钮，由对应来源插件返回分组字段，弹窗统一展示纯文本并处理加载、错误重试及取消请求；交互与验证见[来源版本详情](track-details.md)。

多版本曲目的默认来源由 Server 选择：可用版本优先，其次按源码率从高到低，码率相同时按文件大小从大到小；未知信息排在已知值之后。展开来源版本显示采样率（kHz）、码率、文件大小与“自动默认／手动默认”标记，不再显示默认选择规则说明；采样率缺失时显示“采样率未知”。操作按“详情”“设为默认／取消默认”“播放”排列。用户可“设为默认”，或在手动默认版本处“取消默认”恢复自动选择；手动指定优先，单次播放某版本不改变默认。设置沿用歌曲关联的修订校验、幂等请求及刷新后的结果确认，切换代表来源后保持版本列表展开。“选择封面”位于主曲目行右侧的更多菜单，收起时也可使用；展开后的来源版本菜单和多选菜单不提供该入口。

在线来源的登录按钮位于来源标题右侧，账号状态提示位于下方；已登录时展示平台显示名和头像，未提供头像或图片加载失败时使用默认头像。网易云扫码登录通过弹窗进行：请求开始即显示“正在加载二维码”和转圈动画，图片完成加载后显示二维码；成功后关闭弹窗，关闭或取消时废弃当前挑战及迟到响应。二维码过期只影响本次扫码请求，不表示已登录账号的凭据同时过期；界面仅提示扫码和重新获取二维码。头像字段及支持平台见 [Server 平台登录](../../server/docs/providers/platform-login.md)。

侧栏“歌单”下的“xxx 的歌单”来自该来源的已登录账号歌单接口；来源声明 `playlist.list` 能力且首列表成功非空才显示分类，加载、空列表、失败、离线、未登录与不支持时均隐藏。首列表与浏览页共享请求和缓存，限流遵循 `retryAfter` 最多重试两次；失败后可以刷新来源或歌单重试。缓存绑定 MusicFS 会话、实例、平台账号及请求代次；退出或换账号立即清理旧分类和分页。列表支持不透明游标分页，平台未提供版本时标注读取期间内容可能变化；打开歌单沿用只读预览，只有用户显式导入才写入歌单管理。

浏览器播放按容器、编码和传输方式与 Server 协商能力。Server 保留 FFmpeg 解码/编码和 NCM 解密，音效与声道扩展插件默认禁用；纯解密与解密后转码分别显示说明，不把解密等同于音效，实际格式范围见 [NCM 验证记录](ncm-validation.md)。Web 创建会话声明 `preferences.dspExecution=client`、`gainDb=0`，确认响应执行端和实际服务端处理后，接入浏览器 Web Audio 本地效果链与输出布局。增益、均衡器、压缩、混响和输出声道实时调整，输出默认跟随音源，可选立体声环绕扩展默认关闭。音效设置按实例和账号隔离，输出偏好按稳定服务地址和账号隔离，均保存在当前浏览器，见[本地 DSP](dsp-settings.md)。服务端按编码能力保留源声道，仅做必要的格式适配。转码流的 seek 由 Server 按时间定位并生成相应输出，不能套用原始音频的字节偏移；定位、恢复和换曲后重新接入本地效果链，保留当前参数并释放旧音源及尾音。其他格式、设备与浏览器组合仍需逐项验证。

跨来源切换遵循跨端架构中的恢复决定：只有同一 Recording、另有适用的时间轴兼容证据且输出支持 seek 时才自动恢复进度；条件不满足或定位失败时提示从头播放，音频指纹匹配不等于时间轴兼容。Web 播放适配器维护当前 attemptId，区分歌曲代次与定位意图：忽略旧歌曲/会话结果，同会话 seek/recover 串行确认 attemptId 后再执行最新意图。资源版本改变时清理旧缓冲并加载新地址，不沿用旧字节偏移。timeRestart 使用 Server 返回的 positionOriginMs 映射曲目时间，向 seek/recover 接口提交的 positionMs 均为曲目时间（毫秒）。若桌面端复用设置组件，音频插件及淡出淡入设置通过宿主适配器呈现；浏览器端能力以实际协商结果为准。
