# MusicFS-web 设计入口

当前阶段（2026-10-10）：已由 React 接管界面，提供共享外壳、曲目表、搜索／推荐、歌单、专辑和设置；已有接口接入、未支持能力及验证范围见 [React 交付记录](react-validation.md)。历史最小页面记录保留于 [实施记录](progress.md)。

按 [TypeScript + React 开发方案](react-development.md)和[共享 UI 设计](../../docs/ui-design.md)实现 Web。顶部只保留设置与换肤，不含桌面窗口控制。接口接入范围见[依赖清单](react-api-readiness.md)，Server 侧需求见[缺口交接](../../server/docs/web-ui-api-gaps.md)。

旧版原生 DOM 页面与原生音频控件已移除；React 自定义播放栏沿用原流、处理输出和 NCM 控制核心。管理员可在设置页管理本地音乐目录：允许访问的目录只读展示，通过「添加本地目录」弹窗浏览授权根及子目录、确认候选，再保存实际音乐目录；已有选择可移除。首次没有已选目录，弹窗不预选，取消不改变选择。空目录选择显示待配置，本地来源仍使用插件自述名称「本地音乐」。目录浏览由 Server 限定在 YAML 授权范围内，Web 不读取浏览器所在设备的磁盘。保存目录不自动扫描，导入仍通过已有 Server 扫描接口或脚本发起；下文长期职责不代表全部能力已经交付。

Server 与客户端共同约定由 [MusicFS 跨端架构](../../docs/architecture.md) 管理；[Server 内部设计](../../server/docs/architecture.md)与[音频处理](../../server/docs/audio-processing.md)由 Server 仓库维护。本文件负责 Web 内部职责，OpenAPI、事件协议与协议 SDK 由 Server 发布。

Web 负责浏览器 UI、播放适配器、搜索、聚合歌单、来源选择与设置，并展示 Music Provider 提供的歌单推荐。与桌面端复用组件或资源的方式待验证后确定；不复制桌面宿主逻辑。需验证浏览器 codec、代理 Range、会话授权与部分来源不可用的展示。

本地与在线来源名称由 `/provider-instances`、`/online-instances` 的 `plugin: { id, name, localizedNames, features }` 提供，契约见 [插件身份与名称](../../server/docs/plugin-identity.md)。Web 不维护平台名称或实例别名映射。名称按规范化的当前语言标签精确匹配，再匹配同语言书写体系、基础语言、同语言且书写体系相同的地区标签，最终使用插件默认 `name`；不会把插件名称交给产品文案字典翻译。插件元数据在当前服务端登录会话内共享，退出、登录失效或接受新会话时清空；旧响应不能重新写入。旧 Server 或首次描述失败未返回 `plugin` 时显示“未知来源”，不展示实例配置名或实例编号；插件离线但仍有有效元数据时保留插件名称。用户配置的实例别名仍保留在管理数据中。

设置页采用“音乐源 / 插件管理 / 播放配置 / 其他配置”四个标签页，默认打开音乐源。音乐源包含本地目录和平台账号；插件管理展示现有插件状态及刷新入口，仅管理员可读取管理数据，普通用户看到权限提示；播放配置包含服务端处理偏好和默认音量；其他配置包含语言、外观、连接与账号及退出登录。标签支持左右方向键、Home / End 移动焦点，Enter / 空格确认切换；窄屏横向滚动。所选标签写入地址参数，刷新后保留，旧目录管理链接仍直接打开音乐源。面板按需挂载，离开音乐源时终止尚未完成的平台授权；已保存偏好不受切换影响。

音乐源标签将本地与在线实例合并为单一“音乐来源”，按 `music-source` 功能声明筛选并按实例编号去重；账号登录、校验和退出操作放在对应来源内。元数据缺失的旧接口来源仍显示未知来源。

在线来源的登录按钮位于来源标题右侧，账号状态提示位于下方；已登录时展示平台显示名和头像，未提供头像或图片加载失败时使用默认头像。网易云扫码登录通过弹窗进行：请求开始即显示“正在加载二维码”和转圈动画，图片完成加载后显示二维码；成功后关闭弹窗，关闭或取消时废弃当前挑战及迟到响应。二维码过期只影响本次扫码请求，不表示已登录账号的凭据同时过期；界面仅提示扫码和重新获取二维码。头像字段及支持平台见 [Server 平台登录](../../server/docs/platform-login.md)。

侧栏“歌单”下的“xxx 的歌单”来自该来源的已登录账号歌单接口；来源声明 `playlist.list` 能力且首列表成功非空才显示分类，加载、空列表、失败、离线、未登录与不支持时均隐藏。首列表与浏览页共享请求和缓存，限流遵循 `retryAfter` 最多重试两次；失败后可以刷新来源或歌单重试。缓存绑定 MusicFS 会话、实例、平台账号及请求代次；退出或换账号立即清理旧分类和分页。列表支持不透明游标分页，平台未提供版本时标注读取期间内容可能变化；打开歌单沿用只读预览，只有用户显式导入才写入歌单管理。

浏览器播放按容器、编码和传输方式与 Server 协商能力。当前已接通 Server 的 FFmpeg 解码/编码、Go PCM 增益链与独立 NCM 解密插件；纯解密与解密后转码分别显示说明，不把解密等同于 DSP，实际范围见 [NCM 验证记录](ncm-validation.md)。其他格式与传输组合仍需逐项验证。转码流的 seek 由 Server 按时间定位并生成相应输出，不能套用原始音频的字节偏移。可复用 UI 需表达处理效果的执行端，避免 Server 与桌面 Client 重复执行同一 DSP 效果。

跨来源切换遵循跨端架构中的恢复决定：只有同一 Recording、另有适用的时间轴兼容证据且输出支持 seek 时才自动恢复进度；条件不满足或定位失败时提示从头播放，音频指纹匹配不等于时间轴兼容。Web 播放适配器维护当前 attemptId，区分歌曲代次与定位意图：忽略旧歌曲/会话结果，同会话 seek/recover 串行确认 attemptId 后再执行最新意图。资源版本改变时清理旧缓冲并加载新地址，不沿用旧字节偏移。timeRestart 使用 Server 返回的 positionOriginMs 映射曲目时间，向 seek/recover 接口提交的 positionMs 均为曲目时间（毫秒）。若桌面端复用设置组件，音频插件及淡出淡入设置通过宿主适配器呈现；浏览器端能力以实际协商结果为准。
