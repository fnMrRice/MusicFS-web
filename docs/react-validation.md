# React 页面交付与验证

日期：2026-10-10。依据共享设计重建 Web，旧原生 DOM 入口和 View 已移除。此记录区分已接入能力、界面预留和实际验证，不将设计稿中的所有功能声明为完成。

## 已交付页面

| 区域 | 行为 |
| --- | --- |
| 登录 | 检查实例身份、协议和就绪；显式凭据登录、Cookie 恢复、退出／401 清理 |
| 外壳 | 固定品牌、账号和全宽播放器；独立内容滚动；“我的”“歌单”分别折叠；设置和换肤两个顶部图标 |
| 曲目列表 | 来源过滤、固定修订连续滚动、中文元信息占位、离线／扫描状态、常驻 checkbox、全选范围、明确选中项加入队列或歌单 |
| 搜索 | 页面内关键词、来源、四类型页签、中文输入法、来源独立结果与失败、本机账号隔离最近搜索；仅曲目类型接当前在线 API |
| 推荐 | 按来源排序的歌单卡片，过期缓存与逐源错误；只读预览，显式导入 |
| 歌单 | 创建／改名、添加选中曲目、有序聚合规则、带预期修订编辑、显式生成固定快照、详情曲目、远程导入与同步状态 |
| 专辑 | 当前服务端来源专辑列表与成员详情 |
| 设置 | 实例和真实用户摘要、本机深浅主题、音量、服务端处理偏好、来源可用性和退出 |
| 播放器 | 播放暂停／停止、上一首／下一首、列表循环、会话队列、音量、曲目时间进度、原流／处理／NCM 输出说明、错误后显式重播 |
| 歌词和封面 | 播放器面板按当前来源有效选择读取同源受鉴权内容，歌词作为文本展示 |

播放器独立于路由，最多一个活动媒体元素。媒体进度只更新播放器，曲目表只订阅当前曲目身份。原有播放代次、串行定位／恢复、幂等确认、恢复预算继续使用；更换输出重新应用音量并保留暂停意图。

## 实际验证

- 基线：旧版 27 项单元测试通过后开始迁移。
- 依赖安装：锁文件可执行 `npm ci --include=dev`；React / React DOM 19.3.0、类型包 19.3.0、React Router 7.18.4、Vite React 插件 6.1.2。
- 类型检查、生产构建通过；最终单元测试 **8 个文件、33 项通过**。新增检查包括游标停滞／单在途、显式过期刷新、自定义暂停和输出替换音量、同步任务收据读取、搜索查询绑定、修订校验与写请求同键重试。
- Edge 浏览器回归 **14 项分组通过**：3 项 NCM、7 项真实播放／鉴权／开发代理／键盘、4 项新版界面。真实歌单创建、改名、快照、播放暂停、音量、切页不中断、主题、分组、401 清理均通过。Mock 用例覆盖 1,000 行选择／追加／重试、中文输入法、来源部分失败和身份切换偏好隔离；不代表平台现网能力。
- 已检查 1440×900、1280×800、480×800 截图；窄屏表格可横向滚动，账号和播放控件在视口内，无页面级横向溢出。截图含隔离测试库文件名，不是生产默认数据。
- 表头吸顶与进度条最终样式调整后，再次执行 `ui.spec.ts`，4 项全部通过，并重新检查最终构建截图。

测试截图和媒体证据输出到忽略的 `test-results/`，不包含长期凭据。用户可用 `npm run build`、`npm run test:e2e` 复现；服务端、插件、媒体和测试凭据均位于隔离实例。浏览器解码非零 PCM 不替代人工扬声器听音。

## 未完成能力与边界

1. 本地关键词、专辑／歌手／歌单搜索、全库筛选和排序、收藏、历史缺接口。已保留入口及未支持说明，需求写入 [Server 交接](../../server/docs/contracts/web-integration.md)，没有擅自设计或增加 Server 接口。
2. 在线搜索和歌单观测仅提供资料；不能播放在线结果。没有配置在线来源时页面显示真实空状态；平台成功率与权限需 Server 独立验收。
3. 聚合快照只有来源引用，当前本地曲目需要遍历固定修订音乐库进行关联。缺少批量展示查询，超大库效率有待改进；远程引用不显示假曲名。
4. 未接入人工隐藏规则管理、刮削预览／编辑、原文件写回、目录／插件／平台账号管理。歌词不逐句同步，列表封面为统一占位。
5. 页面使用浏览器 hash 路由；队列仅在当前会话内存，主题／音量／折叠／处理偏好和最近搜索仅在当前浏览器按实例／用户保存，不宣称跨设备同步。
6. 未验证 Firefox、Safari、触屏真机或人工听音；窄视口适配不等于完整移动端产品验收。

## 工程说明

新增代码按 `app`、`layout`、`components`、`features`、`player`、`styles` 划分。前端消费已有 Server 契约，不将手写 TypeScript 类型视为协议权威。核心 API 继续同源 Cookie 与 CSRF，内容域写请求使用幂等键和必要修订。

当前交付为本地工作区修改与可构建的 `dist/`；不包含推送、部署或桌面 Client 修改。
