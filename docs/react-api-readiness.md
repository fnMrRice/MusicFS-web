# React UI 接口现状与待补能力

核对日期：2026-10-10。这是[Web 开发方案](react-development.md)的依赖清单，不是新增 API 定义；Server 拥有 OpenAPI、事件 Schema 和协议 SDK。以下“当前”按本工作区现有契约及 Web 适配器检查，不能代表未核查分支或将来版本。

## 1. 可复用的当前能力

| 能力 | 已有接口／实现 | Web 接入边界 |
| --- | --- | --- |
| 就绪与会话 | `/health/ready`、`/auth/session`；`src/api/auth.ts` | 原有 cookie、CSRF、身份与版本检查保持；React 登录只替换 View |
| 来源 | `/provider-instances`；`src/api/library.ts` | 当前 DTO 只消费 ID、名称、能力、可用性、扫描状态；新契约的导入配置不是已实现的管理 UI |
| 曲目列表 | `/source-tracks`；实例、limit、cursor；固定 libraryRevision | 动态加载复用游标，不能自行添加排序／关键词参数 |
| 播放 | `/playback/sessions`、seek、recover、关闭会话、授权 stream | 保留实际协商与回退，当前浏览器已有原流、处理输出、NCM 证据 |
| 管理／探测 | 当前 Server 有扫描、摘要与指纹相关端点 | 不因端点存在就直接塞入首轮普通用户界面；另行核验权限与任务状态 |

当前 Web `SourceTrack` 包含来源身份、显示名、标题、歌手数组、时长、编码／容器／码率、可用性、资产版本与可选 Recording。未消费完整专辑、封面对象、收藏状态、添加时间或细分不可用原因。扩展字段需兼容未知／null，先补适配与验证，再展示。

## 2. 实施前由 Server 确认的能力

| 界面功能 | 待明确的契约 | 未完成时的页面行为 |
| --- | --- | --- |
| 全库分类、筛选、排序 | 歌手／专辑／流派／目录身份，完整查询条件、稳定排序、游标绑定与准确可选总数 | 先显示现有来源列表；不把当前批次本地重排冒充全库排序 |
| 四类搜索 | 曲目、专辑、歌手、歌单的类型化结果；来源能力、相关顺序、独立游标、结束／过期、可选总数 | 提供明确的未支持状态；不得发送猜测的 `/search` 参数或显示假结果 |
| 专辑／歌手详情 | 来源实例与稳定对象 ID、封面／头像引用、专辑曲序、可浏览的关联对象 | 支持搜索但无详情能力时明确说明，不自行拼接路由对应 API |
| 推荐 | 按实例及账号的排序、分页、来源、有效期、过期与部分失败状态 | 无来源时显示说明，不伪造推荐卡片或自动导入 |
| 歌单 | 读取／管理／导入／绑定、稳定 entryId、revision、同步任务和局部失败 | 未接通前不模拟保存成功，不把界面折叠状态当成持久歌单 |
| 收藏／最近播放 | 当前用户范围、读写／事件、重复行为和持久化；明确历史记录触发时机 | 等待契约；若另选本机历史方案，须明确范围和用户隔离，不能默认替代服务端功能 |
| 完整结果加入队列 | 固定查询／修订的全部结果解析、取消、数量未知、不可用项处理 | 行播放与明确选中项可先做；没有全结果支持时禁用对应命令并说明 |
| 歌词／封面 | 受鉴权对象引用、版本、适用时间轴与已选结果 | 统一占位，不读取 Server 路径，不对新来源沿用旧歌词 |
| 用户资料／偏好 | 是否支持昵称、头像、跨设备主题／偏好存储 | 默认头像与实际用户标识，本机主题与折叠偏好明确不跨设备 |

主仓库架构中的长期路由草案不等于当前 OpenAPI 已实现；本次核对的 OpenAPI 尚未列出搜索、推荐或歌单端点。Web 不在此仓库创建 Server 协议的另一份权威定义。

## 3. 接入约定

1. Server 发布契约后记录 API／Schema 版本和兼容范围，确认请求字段、单位、权限、错误及游标语义，再更新 `src/api/`。生成类型需固定输入与生成过程；手写类型不能替代响应校验。
2. 不同来源的同名对象不自动合并。曲目使用稳定 SourceTrack 身份；聚合歌单使用 entryId／Recording 及明确出处规则，不能用 React key 代替领域身份。
3. 客户端的 capability 描述只消费已经定义的字段；没有开关字段时通过明确的适配版本配置处理，不发明 `supportsX` 并假设 Server 已提供。
4. 查询追加固定相同参数与修订，旧响应不能覆盖新查询；多来源各自管理游标、错误和结束状态。未知总数不显示精确数字。
5. 401 清理用户态；403、未支持、来源离线、游标过期、修订冲突分别呈现。写操作使用既有 CSRF 与修订检查，必要的重试保持幂等键。
6. 契约 Mock 仅用于开发和测试，不作为生产回退；真实功能验收必须包含当前 Server，音频功能还需真实媒体验证。

## 4. 本轮明确排除

Web 不实现小窗／迷你模式、最小化、最大化、关闭窗口，也不为桌面功能预留不可用按钮。本轮不定义桌面宿主通信、桌面歌词窗口、操作系统托盘、全局快捷键或本机插件管理。Client 的更多功能在 Web 完成后另行安排。
