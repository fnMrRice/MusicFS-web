# React UI 接口接入清单

核对日期：2026-10-10。以当前 Server `docs/contracts/openapi.yaml` 与 `http.schema.json` 为依据，修正早期文档中“尚无搜索、推荐、歌单”的过时描述。接口设计归 Server，本轮只接已有接口；缺口见 [Server 交接](../../server/docs/web-ui-api-gaps.md)。

| 页面 | 接入范围 | 边界 |
| --- | --- | --- |
| 登录、设置 | readiness、session、provider-instances | 同源 Cookie、Origin、CSRF；无本机路径和凭据持久化 |
| 曲目列表 | source-tracks 实例过滤、固定修订游标 | 连续滚动；全库关键词、格式、收藏、可播放条件和排序待接口 |
| 在线搜索 | online-instances 与逐实例 search | 仅曲目资料；保留四种结果页签，其他三类显示待支持；无在线播放承诺 |
| 推荐 | recommendations 逐来源卡片和 stale/error | 原始来源顺序，失败不遮挡其他来源；点击只预览 |
| 推荐歌单详情 | 既有在线 playlist observation | 显示真实歌单摘要；不把 external ID 伪装成曲名；显式导入 |
| 个人歌单 | 列表、创建、读取、带 expectedRevision 编辑、重建、固定快照 | 按顺序聚合本地／远程／个人歌单；旧修订拒绝后提示刷新；不写回平台 |
| 远程歌单 | 显式导入、读取、sync-jobs、任务轮询 | POST 返回 jobId 收据，必须读任务终态；保留 stale、错误与上次成功时间 |
| 专辑 | source-albums 列表与详情 | 来源身份；成员按当前库读取，不按同名合并 |
| 播放器 | 原有 session、seek、recover、关闭和同源 stream | 独立全局服务、曲目时间映射、一次一个活动 audio、暂停意图和音量重应用 |
| 歌词／封面 | media-selection 和 media 内容 | 仅当前来源有效绑定；文本展示，不启用逐句定位；列表使用占位封面 |
| 收藏、最近播放 | 保留页面 | 等待 Server 设计，不使用本机数据伪装账号持久化 |

## 仍需 Server 设计

重点是四类完整搜索、本地关键词、分类／过滤／排序、个人收藏和历史、完整查询结果解析、歌单来源引用的批量展示读取。详见 [缺口交接](../../server/docs/web-ui-api-gaps.md)，其中没有新接口路径或自创 Schema。

目前歌单快照只含来源引用，本地曲目展示需要遍历固定修订曲库关联；大库效率存在限制。远程曲目引用不具备音频播放能力，页面明确说明。在线现网结果仍受配置、权限和来源状态影响，界面 Mock 测试不能代替平台验收。

## 安全与一致性

- 身份只使用服务端真实 user ID；主题／音量／分组按实例及用户隔离保存，队列只在会话内存中。
- 查询取消、单在途追加、游标去重、不前进保护、修订过期提示刷新；不将当前部分结果当成全库筛选／排序。
- 勾选仅作用于已返回的稳定曲目 ID，追加项不自动选中；来源切换或刷新清空选择。
- 401 停止播放器，清空队列、曲库缓存和当前用户态；所有写请求使用 CSRF，协议要求的操作带幂等键或预期修订。
- Web 不提供迷你模式、窗口控制、桌面快捷键、操作系统托盘或插件管理。
