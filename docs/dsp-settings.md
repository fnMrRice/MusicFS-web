# 本地 DSP 与服务端格式转换

设置中的「DSP 配置」默认打开「本地音效」。增益、十段均衡器、参数均衡器、动态压缩及混响由浏览器 Web Audio 处理；参数调整立即用于试听，无需重新创建播放会话，点击「保存」才会记住配置。混响使用延迟反馈与滤波网络模拟空间反射。

效果链以紧凑列表从上到下排列，各行默认收起，显示名称、开关、参数摘要和排序操作，点击名称区域展开调整细节。通过手柄拖动排序，支持鼠标、触屏及手柄上的上下方向键；桌面另提供上移／下移按钮，手机省略摘要和这两个按钮以保持行高。支持重复效果、删除、总开关及每个效果独立开关，数量上限为 16。默认总开关开启、效果链为空，添加效果后可直接试听。数字输入在有效范围内实时更新，失焦时将超出范围的数值限制到允许边界。

「均衡器」展开后显示 31、63、125、250、500、1k、2k、4k、8k、16k Hz 十段竖向滑杆，各段范围为 ±12 dB，提供预设与重置；低音／高音增强通过独立搁架滤波器处理。各段实时参与音频处理，手机可在均衡器内部横向滚动查看所有频段。单频段的「参数均衡器」仍可独立添加。

编辑中的效果链仅作为本次页面内的试听草稿，切换设置标签不丢弃草稿；刷新或退出登录后恢复已保存配置。「撤销更改」回到最近保存／加载的配置；「恢复本地默认」清空效果并恢复默认开关，仍需点击「保存」才会持久化。保存成功后显示已保存状态，之后的修改显示未保存提示。

保存只写入当前浏览器的 localStorage，按服务端实例和账号分别保存，不上传到服务器，也不从服务端旧效果链迁移。退出登录清除当前内存配置，保留该账号已保存的浏览器偏好。浏览器不支持音频处理时显示旁路说明；本地存储失败时保留本次编辑、允许重试，并明确提示刷新可能丢失。

「播放配置」提供默认关闭的「切歌淡出淡入」和「自动音量平衡」，与音量、转码偏好一起按浏览器、实例和账号保存。淡出淡入先降低当前曲目的音量，再淡入新曲目；同一个时长分别应用于两段过渡，默认每段 300 毫秒，可设为 100–2000 毫秒。暂停、停止和定位不等待切歌过渡，立即响应。关闭开关保留已选择的时长。

自动音量平衡逐声道估计当前信号的 RMS 电平和峰值，以最响声道驱动统一增益，减小曲目之间的音量差异，避免反相信号抵消或空声道稀释测量。内部目标为 -18 dBFS、最大提升为 6 dB；降低较快、提升较慢，播放初期需要逐步收敛，静音和安静段落不会触发持续提升。这不是整首曲目的离线 LUFS 测量，也不保证不同歌曲达到相同的综合响度；浏览器后台采样可能受节流影响，峰值约束不是真峰值限制器。目标电平与增益限制作为内部策略，不在界面暴露；用户仍可通过主音量调节最终聆听音量。两项功能均在浏览器执行，不请求服务端音效。

「服务端格式转换」是独立的次级入口，只编辑输出声道。服务端继续负责格式转换、转码及必要的声道转换，本地音效的参数修改不触发服务端 DSP 设置或播放会话请求。Web 播放请求声明 `dspExecution: client`，并要求服务端确认该模式，避免旧服务端设置与本地链叠加；旧的固定降低 6 dB 行为已经移除。播放配置中的「强制服务端转码」仅请求转码。

声道设置仍可保存为个人配置或继承全局配置，管理员可编辑全局默认。服务端设置下次播放时生效；保存保留版本冲突提示及幂等重试。此入口不展示效果链或内部 DSP Buffer，并在提交个人配置时使用空效果链，保留服务器提供的处理块大小。服务端 DSP 实现及协议仍保留，音效默认由服务端配置禁用。

服务端接口沿用：

- 个人配置：`GET /api/v1/dsp/settings`、`PUT /api/v1/dsp/settings`。
- 全局默认：`GET /api/v1/dsp/settings/global`、`PUT /api/v1/dsp/settings/global`，仅管理员可用。
- 声道配置验证：`POST /api/v1/dsp/settings/validate`。
- 保存携带 `expectedRevision`、`schemaRevision` 及 `Idempotency-Key`；个人恢复继承传 `inheritGlobal: true`。

验证包括本地参数实时调整、重复效果、折叠保值、鼠标及键盘排序、均衡器滑杆与手机滚动、旁路开关、显式保存／撤销／刷新恢复、实例和账号隔离、存储失败重试、不支持浏览器、禁止将旧服务端效果导入本地、服务端声道配置及版本冲突重试。浏览器端音频节点的信号处理、生命周期和播放协议由相应引擎与播放测试覆盖。
