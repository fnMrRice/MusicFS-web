# 本地 DSP 与输出设置

设置中的「DSP 配置」是连续滚动页面的独立分区，点击顶部分类导航可滚动定位。「本地音效」与「输出设置」以两张卡片同时展示，无需在两者之间切换。增益、十段均衡器、参数均衡器、动态压缩及混响由浏览器 Web Audio 处理；参数调整立即用于试听，无需重新创建播放会话，点击「保存」才会记住配置。混响使用延迟反馈与滤波网络模拟空间反射。

效果链以紧凑列表从上到下排列，各行默认收起，显示名称、开关、参数摘要和排序操作，点击名称区域展开调整细节。通过手柄拖动排序，支持鼠标、触屏及手柄上的上下方向键；桌面另提供上移／下移按钮，手机省略摘要和这两个按钮以保持行高。支持重复效果、删除、总开关及每个效果独立开关，数量上限为 16。默认总开关开启、效果链为空，添加效果后可直接试听。数字输入在有效范围内实时更新，失焦时将超出范围的数值限制到允许边界。

「均衡器」展开后显示 31、63、125、250、500、1k、2k、4k、8k、16k Hz 十段竖向滑杆，各段范围为 ±12 dB，提供预设与重置；低音／高音增强通过独立搁架滤波器处理。各段实时参与音频处理，手机可在均衡器内部横向滚动查看所有频段。单频段的「参数均衡器」仍可独立添加。

编辑中的效果链仅作为本次页面内的试听草稿，滚动浏览其他设置分区不丢弃草稿；刷新或退出登录后恢复已保存配置。「撤销更改」回到最近保存／加载的配置；「恢复本地默认」清空效果并恢复默认开关，仍需点击「保存」才会持久化。保存成功后显示已保存状态，之后的修改显示未保存提示。

保存只写入当前浏览器的 localStorage，按服务端实例和账号分别保存，不上传到服务器，也不从服务端旧效果链迁移。退出登录清除当前内存配置，保留该账号已保存的浏览器偏好。浏览器不支持音频处理时显示旁路说明；本地存储失败时保留本次编辑、允许重试，并明确提示刷新可能丢失。

「播放配置」将音量置于最上方，随后提供「强制服务端转码」及默认关闭的「切歌淡出淡入」「自动音量平衡」，这些偏好一起按浏览器、实例和账号保存。淡出淡入先降低当前曲目的音量，再淡入新曲目；同一个时长分别应用于两段过渡，默认每段 300 毫秒，可设为 100–2000 毫秒。暂停、停止和定位不等待切歌过渡，立即响应。关闭开关保留已选择的时长。

自动音量平衡逐声道估计当前信号的 RMS 电平和峰值，以最响声道驱动统一增益，减小曲目之间的音量差异，避免反相信号抵消或空声道稀释测量。内部目标为 -18 dBFS、最大提升为 6 dB；降低较快、提升较慢，播放初期需要逐步收敛，静音和安静段落不会触发持续提升。这不是整首曲目的离线 LUFS 测量，也不保证不同歌曲达到相同的综合响度；浏览器后台采样可能受节流影响，峰值约束不是真峰值限制器。目标电平与增益限制作为内部策略，不在界面暴露；用户仍可通过主音量调节最终聆听音量。两项功能均在浏览器执行，不请求服务端音效。

「输出设置」位于「本地音效」下方的独立卡片，提供跟随音源、单声道、立体声、5.1 与 7.1。默认跟随音源；浏览器根据设备允许的最大声道数启用可选布局，无法使用保存的布局时自动降至可用声道数，保留用户偏好。页面分别显示设备上限、音源声道和当前输出；未播放时不推测音源声道。实际扬声器输出取决于系统、浏览器和设备配置，设备报告的声道上限不代表已经验证物理环绕输出。

「立体声环绕扩展」默认关闭；关闭时立体声升至 5.1／7.1 只保留左右声道，其余补静音。开启后仅对双声道输入派生中置、低通低频与差分延迟环绕，属于模拟环绕，不是还原原始多声道。原生多声道输入不重复扩展。下混使用明确的声道矩阵，低频声道不混入单声道／立体声，各输出行保留峰值余量；7.1 同侧的侧环绕和后环绕合并为 5.1 环绕。

输出布局与扩展独立于本地音效总开关，位于效果链后、自动音量平衡前；关闭音效仍保留输出布局、淡出淡入与末端音量控制。输出调整立即试听，无需换流、定位或重新创建会话；「保存」「撤销更改」与音效使用相同交互，但配置独立保存，按稳定的 API 访问地址和账号隔离，不使用每次启动都会改变的生命周期实例编号。服务端重启和设备降级不覆盖已保存的布局。

服务端负责解密、格式转换和必要转码，声道扩展插件与音效插件均默认禁用，源码和服务端设置协议保留。Web 播放请求声明 `dspExecution: client`，服务端在创建、定位和恢复时跳过音效与声道扩展，也不套用个人／全局／部署的目标布局；仍按编码格式约束做必要的兼容处理。原生环绕音源在格式可播放时保留声道，不能保持原格式时按浏览器能力选择兼容转码。本地设置不调用 `/dsp/settings`，不改变服务端缓存或时间轴身份。「强制服务端转码」仍只请求格式转换。

验证包括本地参数实时调整、重复效果、折叠保值、鼠标及键盘排序、均衡器滑杆与手机滚动、旁路开关、显式保存／撤销／刷新恢复、实例和账号隔离、存储失败重试、不支持浏览器、设备能力限制及禁止将旧服务端设置导入本地。浏览器端矩阵与扩展的实际信号处理、输出实时切换、生命周期和播放协议由相应引擎与播放测试覆盖。
