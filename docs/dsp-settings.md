# DSP 配置页面

设置中的「DSP 配置」页签允许用户增删、重复添加、调整效果顺序以及编辑插件参数。输入格式、输出格式及输出是否可继续 DSP 来自服务端目录和处理链校验结果；界面不维护另一份效果参数范围。上下移动按钮可用键盘操作。

用户默认使用全局配置。取消「使用全局配置」后，可保存个人配置覆盖全局默认。重新勾选并保存会恢复持续继承，后续管理员修改全局默认也会影响该用户的下一次播放。「恢复默认草稿」仅复制默认值，需保存后生效，不等同于恢复持续继承。

管理员可切换「我的 DSP」和「全局默认 DSP」。两种范围的草稿分开保留；普通用户不展示全局编辑入口，也不请求全局接口。所有修改均在下一次创建播放会话时生效，当前歌曲保持原配置。

DSP Buffer 大小允许填写 64–16384 的整数，默认 4096 帧。页面同时显示 48 kHz 下每个处理块的时长。这是 DSP 调用的处理块大小，不代表网络缓冲大小，也不是音质等级。

保存前自动调用服务端检查串接是否兼容。版本冲突会保留草稿；用户读取最新版本后，检查并再次保存。网络故障后的重试使用相同操作标识，避免不确定结果导致重复保存。服务端不可用时仍展示配置和原因，但禁止提交。

接口：

- 个人配置：`GET /api/v1/dsp/settings`、`PUT /api/v1/dsp/settings`。
- 全局默认：`GET /api/v1/dsp/settings/global`、`PUT /api/v1/dsp/settings/global`，仅管理员可用。
- 串接预览：`POST /api/v1/dsp/settings/validate`。
- 保存携带 `expectedRevision`、`schemaRevision` 及 `Idempotency-Key`。个人恢复继承传 `inheritGlobal: true`，不同时提交 `settings`。

前端验证覆盖参数与 Buffer 边界、重复效果和排序、保存后刷新恢复、非法终端串接、版本冲突保留草稿、失败重试操作标识、个人继承及管理员全局配置，以及桌面和窄屏布局。

真实服务端浏览器测试使用隔离目录和内置 FFmpeg，验证真实目录声明、全局均衡器设置、个人 Buffer 覆盖、恢复继承、页面刷新及服务重启后的持久化。服务端权限和实际音频行为由 Server 仓库对应测试进一步验证。
