# 最小 Web 手动验收

先按 [Server 本地运行说明](../../server/docs/running.md) 构建、配置、启动并扫描；页面本身没有目录配置或扫描按钮。建议使用 Server 的 `tests/testdata/audio` 合成样本与独立测试数据目录，配齐 FFmpeg/ffprobe 和音频 Worker。以下结果需要实际操作后确认，不是已完成人工验收的记录。

| 操作 | 明确预期 |
| --- | --- |
| 1. 登录后点击“刷新列表” | 登录令牌输入清空；显示扫描得到的文件及中文文件名。“可用”表示来源可读取，损坏文件也可能显示该状态，不保证能解码 |
| 2. 不勾选服务端处理，播放 `markers.wav`，暂停再继续 | 播放器显示当前文件与进度，能听到合成音；暂停停止推进，继续恢复。点击“停止”后原生控件移除且声音停止 |
| 3. 再次播放，点击“刷新列表”，随后刷新整个网页 | 列表刷新不打断当前播放；整页刷新依靠会话 Cookie 恢复登录和列表，不自动恢复上次播放 |
| 4. 勾选“服务端处理（降低 6 dB，下一首生效）” | 当前输出不即时改变；重新点击曲目的“播放”后才请求 -6 dB，播放器显示“服务端处理输出”。取消勾选也在重新选曲后生效 |
| 5. 处理播放中先暂停，在“曲目位置（秒）”输入 `4` 并跳转，再继续 | 对6秒标记样本，曲目位置从约4秒继续；原生时间轴从新输出片段的约0秒开始，不能将其当作整首位置。应听到末段较高频标记；未暂停时跳转后直接继续 |
| 6. 播放 `corrupt.wav` 或 `empty.wav`，再选择正常 WAV | 播放明确失败，出现“从头播放”入口；没有无休止恢复。切回正常曲目可继续播放 |
| 7. 播放时点击“退出登录” | 音频停止且控件移除，返回登录页；刷新页面后仍需重新登录 |

## NCM 补充检查

按 [Server NCM 说明](../../server/docs/ncm.md) 配置独立插件并重新扫描。NCM 不需要勾选 -6 dB；该选项只请求额外的增益处理。

- 内部 MP3：选择后显示“服务端解密输出”，验证暂停、继续、停止；时长已知时验证定位。
- 内部 FLAC：配齐音频 Worker 和 FFmpeg/ffprobe 后显示“服务端解密并转码输出”；已知时长时使用上方曲目位置输入，按新片段时间轴验证定位。
- 损坏 NCM：应明确失败，随后正常 WAV 仍能播放；不能因条目显示“可用”就判定解码成功。

可重复的合成 NCM 自动验收命令、摘要和截图见 [NCM 验证记录](ncm-validation.md)。如自行验证真实 NCM，记录来源格式、浏览器、操作和实际听音结果；当前自动化证据不能替代真实变体兼容与人工听音。
