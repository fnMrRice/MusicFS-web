# 来源版本详情

合并歌曲展开后，每个来源版本的“详情”按钮打开独立弹窗。入口不受播放可用性或歌曲合并请求状态影响；仍然可以查看其他来源版本，也可以继续使用原有播放和解除关联操作。

Web 根据所选来源曲目标识调用 `GET /api/v1/source-tracks/{id}/details`，校验响应的曲目和来源实例身份。标题、分组和字段全部由对应来源插件提供，前端使用通用只读文本展示，不推断平台字段、不把曲库行摘要当作插件详情，也不执行插件返回的 HTML 或链接。详细协议由 Server 维护。

弹窗显示加载、空内容和可重试错误；文件已变化时提示重新扫描。关闭弹窗会取消请求，迟到响应不影响随后打开的其他版本。长字段可换行，在窄屏下按字段名与值上下排列；Escape 关闭后焦点返回原“详情”按钮。

自动化验证包括 API 身份与结构校验、不同来源版本的插件字段、纯文本展示、不可播放版本、失败重试、空内容和取消请求。真实服务测试使用隔离的三个 WAV 副本，完成歌曲合并后逐一打开来源详情，核对插件返回的文件路径、目录标识和大小，并验证文件变更时拒绝旧版本详情，不读取用户音乐库。
