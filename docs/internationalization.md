# 多语言

已实现英文、简体中文、繁体中文和日语。登录页与设置页均可切换语言，默认「跟随浏览器」。

## 语言选择

- 按 `navigator.languages` 顺序匹配首个支持的语言；没有匹配项时使用英文。
- `zh-CN`、`zh-SG` 和 `zh-Hans` 对应简体中文；`zh-TW`、`zh-HK`、`zh-MO` 和 `zh-Hant` 对应繁体中文。明确的文字脚本标记优先于地区，单独 `zh` 使用简体中文。
- `en-*` 对应英文，`ja-*` 对应日语。
- 「跟随浏览器」响应浏览器发出的 `languagechange` 事件；手动选择后不随浏览器语言改变。
- 使用当前站点的 `localStorage` 键 `musicfs:language` 保存选择，适用于登录页及全部账号，退出登录不清除。其他同源标签页通过 `storage` 事件同步。存储不可用时仍可在当前页面切换。
- 页面 `html.lang` 和界面日期格式随所选语言更新。API 参数、路由分类值、用户曲名／歌单名／歌词和错误编号不翻译。

## 开发约定

`src/i18n/index.ts` 提供语言检测、订阅和格式化；`LanguageSelect.tsx` 提供统一选择控件。本地字典不依赖在线翻译或额外服务。

`common.ts`、`music.ts`、`notices.ts` 以简体中文原文为键，每项按「英文、繁体中文、日语」顺序存储译文。简体中文直接使用键值。新增界面文字必须补齐三种译文；品牌及服务端原始内容可保留原文。

- 在组件中订阅 `useLocale()`，使用 `tr()` 翻译静态文案、提示、替代文本与无障碍标签。
- 带数量或名称的句子使用完整句式和 `{0}` 等参数，避免拼接单独的中文片段；参数作为 React 文本渲染，不注入 HTML。
- 暂存的错误、扫描及播放状态保留原始消息，在展示时通过 `statusText()` 翻译，确保切换语言后现有提示也会更新。
- 日期通过 `formatDate()` 格式化。用户输入的名称和歌词等不得送入文案翻译函数。
- 语言切换不重新挂载播放器或重置表单、搜索草稿、勾选状态。

## 验证

`tests/unit/i18n.test.ts` 检查语言优先级、中文脚本／地区匹配、未知语言回退、完整译文及参数一致性、存量状态消息翻译。

`tests/e2e/i18n.spec.ts` 使用真实 Edge 和模拟 API，检查登录前自动识别、手动选择与刷新、浏览器事件、禁用存储、跨标签页切换、搜索草稿／勾选保留、用户文本原样显示、错误切换和四种语言的 480px 排版。此测试只需已构建的 `dist/`，不需要 Server。

`tests/e2e/ui.spec.ts` 使用真实 Server 检查播放中切换语言后，音频元素、播放地址和音量保持不变。

运行：`npm run build`、`npm test`、`npm run test:e2e -- i18n.spec.ts ui.spec.ts`。

2026-10-10 验证结果：构建与类型检查通过，43 项单元测试通过；上述 8 项浏览器测试全部通过。已查看英文和日文 480px 设置页截图，并验证播放中切换语言不重建音频元素、不改变播放地址或音量。
