# 固定修订分页

首次请求不带 cursor；后续只使用上次响应的 opaque cursor。每个列表代次固定 libraryRevision；修订不同的页面不可拼接。

刷新、切换来源和 CURSOR_EXPIRED 递增列表代次并中止旧请求。迟到响应必须核对代次；刷新期间保留最后一次成功的数据，失败时提示可能过期。来源切换清空上一来源的内容；普通刷新不改变播放器或活动资产。

同一来源的分页按 sourceTrackId 去重；加载更多只能有一个在途。游标失效后重新读取第一页，不能重用旧游标。

W0.3 完成：状态/取消规则核对；竞态测试在 W2.6 实现。

## React 界面迁移

下一阶段继续使用不透明游标协议，但界面改为滚动接近底部自动追加，不显示分页器、已加载计数或加载更多按钮。加载中仅在末尾显示状态，失败保留数据并提供重试，确认结束后停止请求。修订失效不混拼新旧内容，刷新与选择清理规则以 [React 开发方案第 5 节](react-development.md#5-查询状态与动态加载)为准。当前原生 DOM 页尚未按此规则迁移。
